# Syrinx Studio Portfolio

A sleek, high-performance, and fully responsive digital agency platform built with Next.js, TypeScript, Tailwind CSS, and Framer Motion. Engineered with dark/light mode support, schema-validated forms, and cohesive design components across all pages.







## 🌟 Features

- **Modern UI & Aesthetic:** Built with clean, high-end design aesthetics and full dark/light theme switching.
- **Fluid Micro-Interactions:** Page transitions, scroll reveals, and interactive elements powered by Framer Motion.
- **Type-Safe Codebase:** Scalable architecture written in TypeScript.
- **Form Handling:** Integrated contact interface powered by React Hook Form and Zod schema validation.
- **Accessible Primitives:** Modular UI elements constructed using Radix UI and Shadcn UI.
- **SEO Ready:** Next.js App Router structure optimized for performance and search indexing.

## 📋 Pages Overview

- **Home:** Hero section, service matrix, featured projects, statistics counter, and primary CTA.
- **Services:** Detailed service offerings with interactive cards and process methodology.
- **Portfolio:** Interactive project showcase with filtering and case study previews.
- **About:** Studio vision, core values, team spotlight, and development timeline.
- **Contact:** Interactive inquiry form, FAQ accordion, and location detail matrix.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **UI Components:** [Shadcn UI](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Forms & Validation:** React Hook Form & Zod
